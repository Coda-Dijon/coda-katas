## 9. (Lecture) Et dans une vraie librairie de résilience ?

Pas de code à cette étape : l'objectif est de prendre 15-20 minutes pour découvrir comment des librairies éprouvées implémentent exactement les mêmes concepts que vous venez de coder à la main, et de comparer avec vos propres choix de conception.

### Resilience4j (Java)
[Resilience4j](https://resilience4j.readme.io/) est la librairie de résilience la plus utilisée dans l'écosystème Java aujourd'hui. Quelques pages à parcourir :
- [CircuitBreaker](https://resilience4j.readme.io/docs/circuitbreaker) : retrouvez les états `CLOSED` / `OPEN` / `HALF_OPEN`, le seuil configurable (`failureRateThreshold`), la durée en Open (`waitDurationInOpenState`). Cela vous rappelle quelque chose ?
- [Retry](https://resilience4j.readme.io/docs/retry) : regardez en particulier `IntervalFunction.ofExponentialRandomBackoff(...)`, l'équivalent "prêt à l'emploi" de ce que vous avez codé à la main à l'étape 4.
- [TimeLimiter](https://resilience4j.readme.io/docs/timeout) : l'équivalent de votre `TimeoutWeatherApi`.
- La page [Getting Started](https://resilience4j.readme.io/docs/getting-started-3) montre comment on **compose** plusieurs de ces décorateurs ensemble (via `Decorators.ofSupplier(...).withCircuitBreaker(...).withRetry(...)`) — comparez avec votre propre réponse à l'étape 8.

### Polly (.NET)
Si vous connaissez ou pratiquez le C#, [Polly](https://www.pollydocs.org/) propose les mêmes concepts (`CircuitBreakerStrategyOptions`, `RetryStrategyOptions`, `TimeoutStrategyOptions`), assemblés dans un `ResiliencePipeline`. Leur documentation sur l'[ordre des stratégies dans un pipeline](https://www.pollydocs.org/pipelines/index.html) rejoint directement la discussion de l'étape 8.

### Discussion
- Qu'est-ce que ces librairies vous offrent que votre implémentation maison n'a pas (métriques, événements, intégrations avec des dashboards, thread-safety éprouvée en production...) ?
- Qu'avez-vous gagné à l'avoir implémenté vous-même d'abord, plutôt que de partir directement sur l'une de ces librairies ?
- Dans un vrai projet, à partir de quel moment recommanderiez-vous de remplacer une implémentation maison par une librairie établie ?
