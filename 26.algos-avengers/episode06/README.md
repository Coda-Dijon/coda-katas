### Episode 6 : Le Seuil d'Alerte

Pour une mission à haut risque, seuls les héros dépassant un certain niveau de puissance peuvent être envoyés.

Ta mission : compter combien de membres de l'équipe dépassent strictement un seuil donné.

## Pièges
- Équipe vide
- Personne ne dépasse le seuil
- Tout le monde dépasse le seuil

```c
int count_above_threshold(const Avenger *team, int count, int threshold);
```
